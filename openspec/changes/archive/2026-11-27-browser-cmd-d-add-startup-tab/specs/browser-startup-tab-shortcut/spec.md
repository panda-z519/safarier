# browser-startup-tab-shortcut Specification

## Purpose

定义在 Safarier 浏览器窗口中通过快捷键 `⌘D` 或菜单项将当前页面（或手动编辑后的网址）以原生 macOS Safari 风格下拉确认表单加入当前环境「启动页签」的完整行为契约，包括网址编辑与快捷裁剪、添加位置选择、重复与暂停态处理、跨进程原子持久化以及环境管理器实时同步。

## ADDED Requirements

### Requirement: 浏览器窗口提供 ⌘D 添加启动页签入口
浏览器窗口的顶部「文件」菜单 MUST 提供「添加到启动页签…」菜单项并绑定快捷键 `⌘D`，在浏览窗口处于活动状态时 SHALL 可触发该操作；当浏览器进程没有活动浏览窗口时，该菜单项 SHALL 不可用。

#### Scenario: 在正在浏览网页的窗口按下 ⌘D
- **GIVEN** 某环境的浏览器窗口正在显示一个有效的 `http` 或 `https` 网页
- **WHEN** 用户按下 `⌘D` 或点击顶部「文件 → 添加到启动页签…」
- **THEN** 浏览器窗口从工具栏正下方居中滑出原生模态下拉表单（Sheet），且网址输入框默认预填当前网页地址并处于全选聚焦状态

#### Scenario: 在空白起始页或历史记录视图按下 ⌘D
- **GIVEN** 浏览器窗口当前显示空白起始页或历史记录页面（无当前网页地址）
- **WHEN** 用户按下 `⌘D` 或点击顶部「文件 → 添加到启动页签…」
- **THEN** 下拉表单照常打开，网址输入框保持空白并自动获得焦点，允许用户手动输入或粘贴网址

#### Scenario: 浏览器进程无可见窗口时校验菜单项
- **GIVEN** 浏览器进程仍在运行但当前没有打开任何浏览窗口
- **WHEN** 用户打开顶部「文件」菜单查看「添加到启动页签…」
- **THEN** 该菜单项处于禁用（变灰）状态，避免对无窗口上下文弹出表单

---

### Requirement: 原生 Safari 风格下拉表单支持网址编辑、快捷裁剪与位置选择
确认表单 MUST 以紧贴浏览器工具栏正下方的原生模态 Sheet 样式呈现，清晰标注目标环境名称，允许用户编辑网址、使用快捷按钮整理网址、选择添加位置，并通过标准键盘按键完成确认或取消。

#### Scenario: 修改网址并省略协议自动补全
- **GIVEN** 确认表单已打开，用户将输入框内容修改为省略协议的域名（如 `example.com/dashboard`）
- **WHEN** 表单实时校验输入并由用户按下 `↩` 或点击「添加」
- **THEN** 系统按既有网页网址规则自动规范化为 `https://example.com/dashboard`（`localhost` 与 IP 地址使用 `http://`）并写入启动页签

#### Scenario: 使用「去掉参数」与「仅保留域名」快捷整理网址
- **GIVEN** 当前输入框中的网址包含查询参数、锚点或深层路径（如 `https://github.com/Cd1s/safarier/issues?q=open#top`）
- **WHEN** 用户点击「去掉参数」按钮
- **THEN** 输入框更新为 `https://github.com/Cd1s/safarier/issues`，且界面显示「还原原网址」按钮
- **WHEN** 用户点击「仅保留域名」按钮
- **THEN** 输入框更新为 `https://github.com`；点击「还原原网址」后可恢复为表单打开时的原始网页地址

#### Scenario: 选择添加位置（末尾或设为首页）
- **GIVEN** 确认表单已打开且目标环境已有若干启动页签
- **WHEN** 用户保持「添加位置」下拉框为默认项「启动页签末尾」并确认
- **THEN** 新启动页签以启用状态追加到目标环境启动页签列表末尾
- **WHEN** 用户在「添加位置」下拉框选择「第 1 位 · 设为首页」并确认
- **THEN** 新启动页签以启用状态插入到目标环境启动页签列表第 1 位

#### Scenario: 网址无效或为空时阻止提交
- **GIVEN** 确认表单已打开
- **WHEN** 输入框为空，或输入了包含空格、无有效主机名、非 `http`/`https` 协议（如 `file:///tmp`、`javascript:alert(1)`）的内容
- **THEN** 主按钮保持禁用状态且按 `↩` 不提交；非空无效输入时在输入框下方显示明确错误提示

#### Scenario: 取消表单不产生任何持久化改动
- **GIVEN** 确认表单已打开且用户已修改输入框或下拉选项
- **WHEN** 用户点击「取消」或按下 `Esc`
- **THEN** 表单关闭，目标环境的启动页签配置保持原样不被写入

---

### Requirement: 重复网址与暂停态智能提示
确认表单在打开与编辑网址期间 MUST 对照目标环境最新的启动页签列表进行检测，区分“已启用重复项”与“已暂停重复项”并给出对应交互反馈。

#### Scenario: 输入网址已存在于启用状态的启动页签中
- **GIVEN** 目标环境启动页签中已包含 `https://mail.google.com/` 且处于启用状态
- **WHEN** 用户在表单中预填或输入规范化后等价的该网址
- **THEN** 输入框下方显示温和提示指出该网址已在启动页签中及所在序号，主按钮文案调整为「仍要添加」，允许用户修改网址、取消或显式追加新项

#### Scenario: 输入网址已存在但处于暂停状态
- **GIVEN** 目标环境启动页签中已包含 `https://calendar.google.com/` 但当前处于暂停状态
- **WHEN** 用户在表单中预填或输入规范化后等价的该网址并确认
- **THEN** 输入框下方提示该网址已存在但处于暂停状态，主按钮切换为「重新启用」；用户确认后直接将该已有项恢复为启用状态（若同时选择「设为首页」则将其移至首位），不产生重复条目

---

### Requirement: 跨进程原子写入、撤销回滚与环境管理器实时同步
浏览器进程写入启动页签 MUST 在跨进程文件锁内读取最新环境配置并仅更新目标环境的启动页签字段，SHALL 立即通知同工作目录的环境管理器刷新显示，同时提供短时可撤销的轻反馈，且不破坏当前打开的标签页与管理器未保存草稿。

#### Scenario: 并发修改环境其他配置时不发生字段覆盖
- **GIVEN** 某环境的浏览器已启动，随后用户在环境管理器中修改并保存了该环境的代理节点或备注
- **WHEN** 用户在浏览器窗口按 `⌘D` 新增一条启动页签并确认
- **THEN** 落盘后的环境配置同时保留管理器新保存的代理/备注以及本次新增的启动页签，且不改动当前浏览器窗口已打开的标签页

#### Scenario: 环境管理器与浏览器分屏时实时看到新增项
- **GIVEN** 同工作目录的环境管理器正在运行且正在查看该环境详情（无未保存草稿）
- **WHEN** 用户在浏览器窗口按 `⌘D` 成功添加或重新启用一条启动页签
- **THEN** 环境管理器无需手动切换窗口或按 `⌘R`，立即刷新并展示最新的启动页签列表

#### Scenario: 管理器存在未保存草稿时保留冲突保护
- **GIVEN** 环境管理器中用户正在编辑该环境且有未保存的改动
- **WHEN** 浏览器窗口通过 `⌘D` 原子写入了一条新的启动页签
- **THEN** 管理器保持用户当前未保存草稿不被悄悄覆盖，并在用户后续尝试保存时继续触发既有的外部变更冲突提示

#### Scenario: 添加成功后支持一键撤销
- **GIVEN** 用户刚通过 `⌘D` 成功添加或重新启用了一条启动页签
- **WHEN** 浏览器窗口底部展示轻提示条且用户在提示消失前点击「撤销」
- **THEN** 系统再次在文件锁内原子回滚本次新增（删除刚插入的项，或将刚重新启用的项恢复回原位置与暂停状态），并再次通知管理器实时刷新

#### Scenario: 设为首页后同步当前窗口的 ⇧⌘H 起始网址
- **GIVEN** 用户在浏览器窗口通过 `⌘D` 新增启动页签并选择了「第 1 位 · 设为首页」（或目标环境原本没有启用中的启动页签）
- **WHEN** 写入成功后用户在当前浏览窗口按下 `⇧⌘H`（起始页面）
- **THEN** 浏览器导航至新的首位启用启动页签网址，而当前已打开的其他标签页不受任何影响

#### Scenario: 目标环境配置已不存在时的安全失败处理
- **GIVEN** 当前运行的浏览器对应的环境记录已在外部被删除
- **WHEN** 用户在浏览器窗口通过 `⌘D` 确认添加启动页签
- **THEN** 系统不创建孤儿记录、不崩溃，在表单中给出明确错误提示并保持窗口稳定运行

---

### Requirement: 隔离边界与多语言本地化完整覆盖
跨进程配置变更通知 MUST 按规范化的工作目录路径隔离且仅在本地投递，不发起网络请求；所有新增用户可见文案 MUST 补齐简体中文、英文与俄文本地化条目并通过本地化覆盖率校验。

#### Scenario: 不同工作目录之间的配置变更通知互不干扰
- **GIVEN** 本机正式工作目录已运行一个环境管理器实例
- **WHEN** 自动化测试或隔离工作目录中的浏览器进程触发启动页签写入与变更通知
- **THEN** 正式工作目录的环境管理器不会受到测试工作目录通知的干扰

#### Scenario: 多语言界面与本地化测试通过
- **GIVEN** 界面语言设置为简体中文、英文或俄文
- **WHEN** 用户打开浏览器「文件」菜单并触发 `⌘D` 下拉表单查看标题、按钮、提示与错误信息
- **THEN** 所有新增可见文本均显示对应语言的准确译文，且无缺失键或格式占位符不匹配
