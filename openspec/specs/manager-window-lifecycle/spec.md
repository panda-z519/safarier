# manager-window-lifecycle Specification

## Purpose

定义 Safarier 图形管理器的窗口关闭留驻、单实例协调，以及在浏览器环境窗口运行期间从系统入口与浏览器入口可靠唤醒或重新拉起管理窗口的完整行为契约，同时保障既有环境数据隔离与多工作目录测试互不干扰。

## Requirements

### Requirement: 关闭管理窗口后管理器进程留驻
图形管理器在用户关闭管理窗口时 MUST 保留管理器进程在后台运行，而不自动终止进程；仅在用户显式退出应用时终止管理器进程，且管理窗口关闭后重新打开时 SHALL 保留尚未保存的编辑状态与界面监控状态。

#### Scenario: 有浏览器窗口运行时关闭管理窗口
- **GIVEN** 图形管理器正在运行，且至少有一个环境浏览器窗口正在运行
- **WHEN** 用户点击管理窗口左上角关闭按钮或按下 `⌘W` 关闭管理窗口
- **THEN** 管理窗口关闭，管理器进程保持运行不退出，且正在运行的浏览器窗口不受影响

#### Scenario: 无浏览器窗口运行时关闭管理窗口
- **GIVEN** 图形管理器正在运行，且当前没有任何环境浏览器窗口在运行
- **WHEN** 用户点击管理窗口左上角关闭按钮或按下 `⌘W` 关闭管理窗口
- **THEN** 管理窗口关闭，管理器进程遵循 macOS 原生惯例保持运行不退出

#### Scenario: 用户显式退出管理器
- **GIVEN** 图形管理器正在运行（无论管理窗口当前可见还是已关闭）
- **WHEN** 用户在管理器激活状态下按下 `⌘Q` 或选择菜单「退出 Safarier」
- **THEN** 管理器进程正常退出，且正在运行的独立浏览器环境进程保持运行不受影响

### Requirement: 通过程序坞和跨进程切换重新唤醒管理窗口
当管理器进程仍在运行但管理窗口已关闭时，系统 MUST 在用户重新激活或重新打开管理器进程时自动将管理窗口重新显示并置前。

#### Scenario: 点击管理器程序坞图标唤醒主窗口
- **GIVEN** 管理器进程仍在运行，但其主管理窗口已关闭
- **WHEN** 用户点击程序坞中对应管理器的图标触发应用重开事件
- **THEN** 管理器重新打开并显示主管理窗口，且窗口置前获得焦点

#### Scenario: 从浏览器通过窗口循环快捷键切回管理器
- **GIVEN** 管理器进程仍在运行但主管理窗口已关闭，且桌面上有一个正在运行的浏览器窗口
- **WHEN** 用户在浏览器窗口中按下跨进程窗口循环快捷键（`⌘\`` 或中文输入法下的 `⌘·`）切换到管理器进程
- **THEN** 管理器激活为前台应用，并自动重新显示主管理窗口

#### Scenario: 在管理器自身菜单或程序坞右键菜单唤醒主窗口
- **GIVEN** 管理器进程仍在运行，但其主管理窗口已关闭
- **WHEN** 用户点击管理器菜单栏或管理器程序坞右键菜单中的「打开环境管理器」
- **THEN** 主管理窗口重新显示并置前

### Requirement: 浏览器窗口提供打开环境管理器入口
每一个环境浏览器进程 MUST 在顶部「窗口」菜单以及程序坞右键菜单中提供「打开环境管理器」入口，无论当前管理器进程处于显示、隐藏还是已退出状态，用户点击后 SHALL 都能打开或唤醒主管理窗口；本能力 MUST 保持界面克制，不在系统右上角菜单栏常驻状态图标。

#### Scenario: 管理器在后台存活时从浏览器菜单打开管理器
- **GIVEN** 管理器进程仍在运行但主管理窗口已关闭，用户当前在浏览器窗口中操作
- **WHEN** 用户点击浏览器顶部「窗口 → 打开环境管理器」（或按下快捷键 `⌥⌘0`）
- **THEN** 正在运行的管理器进程被激活，其主管理窗口重新显示并置前，且不会启动第二个管理器进程

#### Scenario: 管理器已退出时从浏览器菜单重新拉起管理器
- **GIVEN** 管理器进程已经退出，桌面上仍有浏览器窗口在运行
- **WHEN** 用户点击浏览器顶部「窗口 → 打开环境管理器」（或按下快捷键 `⌥⌘0`）
- **THEN** 系统以独立新实例方式启动图形管理器并显示主管理窗口

#### Scenario: 通过任意浏览器图标的程序坞右键菜单打开管理器
- **GIVEN** 桌面上有浏览器窗口在运行（无论管理器当前存活还是已退出）
- **WHEN** 用户在程序坞中右键点击浏览器图标并选择「打开环境管理器」
- **THEN** 主管理窗口被唤醒置前（管理器存活时）或被新实例拉起显示（管理器已退出时）

#### Scenario: 浏览器进程无可见窗口时菜单入口仍可用
- **GIVEN** 浏览器进程处于运行状态但暂时没有可见浏览窗口
- **WHEN** 用户打开浏览器顶部「窗口」菜单查看「打开环境管理器」
- **THEN** 该菜单项保持可用状态，点击后能够唤醒或拉起图形管理器

### Requirement: 管理器单实例运行与重启兼容
同一个工作目录下 MUST 最多只允许一个图形管理器实例运行；当重复启动第二个管理器实例时 SHALL 自动唤醒已有实例并退出自身，同时界面语言切换与应用内自动更新触发的管理器重启 MUST 能够顺利拉起新实例，不被单实例保护误拦截。

#### Scenario: 重复启动同工作目录的管理器实例
- **GIVEN** 工作目录下已有一个图形管理器实例正在运行（无论窗口可见还是已关闭）
- **WHEN** 用户或外部命令再次启动同一工作目录的图形管理器
- **THEN** 新启动的实例唤醒已存在的管理器并使其主窗口置前，随后新实例静默退出，不产生双开窗口

#### Scenario: 管理器切换界面语言后重启
- **GIVEN** 图形管理器正在运行并持有单实例状态
- **WHEN** 用户在管理器菜单切换界面语言触发重启
- **THEN** 旧实例在拉起新实例前释放单实例占用，新实例按新语言正常启动并显示主窗口

#### Scenario: 管理器应用内自动更新后重启
- **GIVEN** 图形管理器完成新版应用包校验与替换，准备重启到新版本
- **WHEN** 管理器触发自动更新重启流程
- **THEN** 旧实例在拉起新版本前释放单实例占用，新版本管理器正常启动并显示主窗口

### Requirement: 跨进程唤醒隔离与数据兼容
管理器的单实例识别与跨进程唤醒机制 MUST 按工作目录隔离且仅在本地执行，不发起网络请求、不依赖私有系统接口、不改变现有应用包的应用编号（Bundle ID），并补齐新增可见文案的中英文本地化映射。

#### Scenario: 不同工作目录之间的唤醒与单实例互不干扰
- **GIVEN** 用户本机正式工作目录已运行一个图形管理器实例
- **WHEN** 自动化测试或隔离环境使用独立工作目录触发管理器锁操作或跨进程唤醒信号
- **THEN** 正式工作目录中的管理器实例既不会阻止测试实例运行，也不会被测试发出的唤醒信号误激活

#### Scenario: 升级后既有持久环境网站数据保持完整
- **GIVEN** 用户在旧版本中已存在带有 Cookie 与登录状态的持久环境
- **WHEN** 用户升级到包含本变更的版本并启动对应环境
- **THEN** 应用保持原有应用编号与网站数据存储映射，所有既有环境登录态、本地存储及「清理沙盒数据」功能保持原样可用
