# 启动页签

在环境的新建或详情表单中，使用“启动页签”分组设置环境启动时自动打开的网址。

- 点击“添加网址”新增一项，默认勾选“启动时打开”。
- 取消勾选可暂停自动打开，网址仍保留；重新勾选即可恢复。
- 使用上移、下移调整顺序，使用删除按钮移除网址。
- 点击“保存”或“创建”后生效；详情页的“还原”会恢复最新已保存配置。
- 环境正在运行时，修改只影响下次启动，不会关闭或追加当前页签。

启动时，所有勾选项按顺序在同一窗口中打开，默认选中第一项。未配置网址或全部暂停时，打开一个起始页。单个网站加载失败不影响其他页签。

支持有效的 HTTP/HTTPS 网页地址，输入时可以省略协议，例如 `example.com` 会规范化为 `https://example.com`。暂停项也需要有效网址；新增空行需要填写或删除后才能保存。

“回到起始页”使用第一个启用网址，没有启用项时显示起始页。暂停只影响自动启动；手动访问网址和菜单中的“重新打开上次会话的所有标签页”仍可打开这些页面。

## 命令行

创建或更新环境时，可以重复传入 `--url`，按参数顺序保存为启用的启动页签：

```sh
safarier profile create --name 示例 \
  --url https://example.com/first \
  --url https://example.com/second

safarier profile update PROFILE_ID \
  --url https://example.com/second \
  --url https://example.com/first
```

更新时，传入 `--url` 会替换整个列表；不传则保留网址、顺序和暂停状态。`--url none` 清空列表。逐项暂停在图形界面中设置。

```sh
safarier profile update PROFILE_ID --url none
safarier launch PROFILE_ID --url https://example.com/once
```

`launch --url` 只覆盖本次启动，不修改保存的列表。探针只使用第一个启用网址，也可用 `probe --url` 显式指定。

## 配置兼容

新版以 `startupTabs` 为唯一配置来源，每项包含 `id`、`url` 和 `isEnabled`，数组顺序即打开顺序。

旧配置没有 `startupTabs` 时，原 `startURL` 自动读取为一个启用项；只要新字段存在，即使它是空数组，也不会回退打开旧网址。保存时同时写入第一个启用网址作为旧版的 `startURL`；全部暂停或清空时不写旧字段。

旧版只认识一个网址，无法保留完整的启动列表和暂停状态。需要回退版本时，应先备份元数据目录中的 `profiles.json`，完整恢复依赖备份。
